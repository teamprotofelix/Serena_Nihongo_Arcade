# 🎌 SERENA NIHONGO ARCADE — 일본어 회화 어드벤처 v2.2

**가볍고 빠르게 실행되는 순수 HTML/CSS/JavaScript 일본어 회화 아케이드 게임**입니다. GitHub Pages에서 정적 사이트로 호스팅할 수 있고, 계정이나 API 키, npm 패키지, 외부 CDN이 필요하지 않습니다.

## 🌸 핵심 학습 방식

일본어 회화는 단어를 외우는 것보다 **상대방의 말을 듣고 즉시 적절한 문장을 말하는 능력**이 중요합니다. 이 게임은 다음 흐름을 반복하도록 설계했습니다.

1. **미리 익히기** — 회화 스테이지 시작 전 대표 답변 4개를 일본어 + Hepburn 로마자(장음 ō/ū) + 한국어 뜻으로 미리 봅니다.
2. **상황에 반응하기** — 공항·카페·학교 등에서 NPC의 일본어를 듣고 상황에 맞는 답변을 선택합니다.
3. **즉시 해설** — 정답·한글 뜻·핵심 문법을 확인하고 TTS로 다시 들어 봅니다.
4. **실수 복습** — 틀린 문제는 회화 세션 끝에 한 번 더 등장하고, 복습 목록에도 기록됩니다.
5. **직접 조립하기** — 조각으로 나뉜 문장을 스스로 완성하면서 일본어 어순을 연습합니다.

## 🎮 게임 모드

- **스토리 미션** — 원하는 장소와 수준(전체/N5형/N4형) 선택. 3개의 하트, 콤보 점수, 스테이지 별 등급.
- **🎧 리스닝 챌린지** — 일본어 글자를 가린 뒤 브라우저 TTS로 질문을 재생하여, **귀로 듣고 응답**하는 연습. TTS가 나오지 않을 경우 `🔊 다시 듣기` 또는 `💡 문장 보기`로 텍스트 학습 가능.
- **🧩 문장 조립 배틀** — N5형 기초 문장으로 마련된 총 18개 조립 미션 중 무작위 10개를 골라 조각을 순서대로 누르며 문장을 구성. 단순 정답 선택에서 한 단계 진전된 *생산형 회화* 연습.
- **⚡ 60초 스피드 러시** — 제한 시간 안에 최대한 빠르고 정확하게 답하기.
- **📒 회화 도감** — 원문·히라가나·Hepburn 로마자·한국어 뜻·정답 발음·개별 연습.
- **🔁 오답 복습** — 이전에 틀린 문장 재도전.

### 게임 난이도와 소리

- **입문:** 질문의 일본어·히라가나·로마자·한국어 뜻 표시, 25초 제한(스토리).
- **기본:** 한국어 도움 가림, 17초 제한(스토리).
- **도전:** 한국어 도움 가림, 11초 제한(스토리).
- **발음:** 일본어 TTS 재생 속도를 `천천히` 또는 `보통`으로 선택.
- **효과음:** Web Audio API로 생성하며 상단 버튼으로 끌 수 있음.

## 🚀 GitHub Pages 배포

**ZIP 파일 자체를 저장소에 올리면 사이트가 실행되지 않습니다. ZIP을 풀어 내부 파일과 폴더를 업로드해야 합니다.**

1. ZIP의 압축을 해제합니다.
2. GitHub 저장소의 `main` 브랜치 **최상위 경로**에 `index.html`, `game.js`, `data.js`, `styles.css`, `pwa.js`, `service-worker.js`, `manifest.webmanifest`, `assets/`, `.github/` 등 **압축 내부의 모든 내용**을 업로드합니다.
3. `Settings → Pages → Build and deployment → Deploy from a branch` 선택.
4. `main` / `/ (root)` 설정 후 저장합니다.
5. 게시된 Pages URL에서 게임을 열어 보세요. (예: `https://계정.github.io/저장소명/`)

상대 경로를 사용하므로 `https://계정.github.io/저장소명/`처럼 하위 경로에서 실행됩니다. 설치나 별도 빌드가 필요하지 않습니다.

### 오프라인 사용 / PWA

- GitHub Pages에서 **첫 방문 시 모든 게임 이미지와 코드를 서비스 워커 캐시에 저장**하도록 설계했습니다. 설치가 성공하면 다음 방문에 인터넷 없이도 플레이할 수 있습니다.
- `manifest.webmanifest`와 WebP 앱 아이콘이 있어, 지원 브라우저에서 홈 화면/앱 목록에 추가할 수 있습니다.
- **TTS는 기기와 브라우저에 설치된 일본어 음성 엔진에 의존**하므로 오프라인에서 소리가 나오지 않을 수 있습니다. 이 경우 텍스트로 계속 플레이할 수 있습니다.
- `index.html`을 파일로 직접 여는 경우 게임은 작동하지만, 서비스 워커/PWA 설치는 HTTPS 사이트에서만 활성화됩니다.
- 학습 진도와 설정은 브라우저의 `localStorage`에 저장됩니다. 별도 서버로 업로드하지 않으며, 브라우저 데이터 삭제 시 진도가 사라질 수 있습니다.

```text
index.html               # 게임 화면 진입점

manifest.webmanifest     # 설치 가능한 앱 정보
favicon.webp             # 브라우저 아이콘
.nojekyll                # GitHub Pages 경로 보존
assets/                  # 고화질 WebP 배경/NPC/마스코트/앱 아이콘 (총 26종)

README.md
```

이미지는 모두 WebP 형식입니다. 추가 생성한 고해상도 NPC 4종은 **투명도를 유지하는 손실 압축 WebP**로 재최적화해 시각적 품질과 전송 용량의 균형을 맞췄습니다.

## 🧪 테스트

Node.js 22 이상이라면 의존성 설치 없이 다음 명령으로 검사할 수 있습니다.

```bash
node --check game.js
node --check data.js
node --check pwa.js
node --check service-worker.js
node tests/validate.cjs
```

GitHub Actions가 허용된 저장소에서는 `.github/workflows/ci.yml`로 push·PR마다 같은 검사를 진행합니다. GitHub Pages 배포는 별도 `Settings → Pages` 설정이 필요합니다.

브라우저 화면과 이벤트는 **데스크톱(1440px), 모바일(390px)** 가상 환경에서 주요 시나리오를 검사했습니다. 자동 브라우저의 로컬 URL 탐색 제한 때문에 JS/CSS/이미지를 인라인으로 주입하는 시험 페이지에서 렌더링과 클릭을 검증했습니다. 실제 GitHub Pages 배포, 서비스 워커 설치, 일본어 TTS 기기별 재생은 배포 후 실기기에서 최종 확인해 주세요.
